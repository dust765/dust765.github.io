The Project

Why Dust765 Exists

Dust765 was born from frustration — not with Ultima Online itself, but with the drama and gatekeeping in its open-source ecosystem.

"This project was created to show the community that open source isn't meant for cliques and high school drama — it's meant for innovation."
— A penny for your thoughts, the adder that prays beneath the rose.

We forked ClassicUO, stripped the politics, and focused on what actually matters: a fast, stable, cross-platform client that respects every player.

What We Built

Features

Combat
Combat Enhancements

Last target tracking, stun/mortal highlight, swing line indicators, sync position on attack, and UO Classic Combat integration.

Visual
Visual Helpers

Glowing weapons, highlight friends and guild members, gargoyle fly state override, health indicator overlay.

Magic
Casting & Spells

Active spell icon on cursor, OnCasting gump, self-cast last target highlight, fast rotation support.

Interface
Modern UI

Custom title bar with HP/Mana/Stamina bars, borderless window with resize edges, redesigned login screen.

Platform
Cross-Platform

Native builds for Windows x64, Linux x64, and macOS. All platforms first-class support.

Plugins
Plugin Compatibility

Razor Enhanced, UOStealth, ClassicAssist, and more — all work out of the box. No patching required.

Automation
Auto Loot & Macros

Built-in auto-loot system, UO Classic Combat macro helpers, action bar, scriptable macro support.

Info
Info & Nameplates

Configurable nameplates, health bars, info bars, cooldown bars, counters, and in-game buff bar.

Updates
Auto Updater

Integrated update manager checks for new releases and applies them automatically.

Getting Started

Installation

Dust765 is a standalone client — no source code required. Download, extract, and point it at your UO installation.

  1. Download Dust765-Windows-x64.zip from the Releases page.
  2. Extract to a folder (e.g. C:\Games\Dust765).
  3. Open settings.json and set uo_path to your UO directory.
  4. Run ClassicUO.exe — no wizard needed.
  1. Download Dust765-linux.zip from Releases.
  2. Extract: unzip Dust765-linux.zip -d ~/Dust765
  3. Install Mono: sudo apt install mono-complete
  4. Run: mono ClassicUO.exe
  1. Download Dust765-mac.zip from Releases.
  2. Install Mono: brew install mono
  3. Edit settings.json to point to your UO files.
  4. Run: mono ClassicUO.exe
  1. Clone: git clone --recurse-submodules https://github.com/dust765/ClassicUO.git
  2. Restore: dotnet restore src/ClassicUO.Client/ClassicUO.Client.csproj
  3. Build: dotnet build ... -c Release

Requirements

Prerequisites

  • Ultima Online client files (licensed copy)
  • .NET Framework 4.8 (Windows)
  • Mono Runtime (Linux / macOS)
  • 64-bit OS (x64 architecture)
  • OpenGL 3.0+ GPU
