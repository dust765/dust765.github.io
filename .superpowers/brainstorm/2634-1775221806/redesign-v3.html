Getting Started

Installation

Standalone client — no source code required. Download, extract, and point it at your UO installation.

  1. Download Dust765-Windows-x64.zip from the Releases page.
  2. Extract to a folder (e.g. C:\Games\Dust765).
  3. Open settings.json — set uo_path to your UO directory.
  4. Run ClassicUO.exe — no wizard needed.
  1. Download Dust765-linux.zip from Releases.
  2. Extract: unzip Dust765-linux.zip -d ~/Dust765
  3. Install Mono: sudo apt install mono-complete
  4. Run: mono ClassicUO.exe
  1. Download Dust765-mac.zip from Releases.
  2. Install Mono: brew install mono
  3. Edit settings.json for your UO files.
  4. Run: mono ClassicUO.exe
  1. Clone: git clone --recurse-submodules https://github.com/dust765/ClassicUO.git
  2. Restore: dotnet restore src/ClassicUO.Client/ClassicUO.Client.csproj
  3. Build: dotnet build ... -c Release

Requirements

Prerequisites

  • Ultima Online client files (licensed copy)
  • .NET Framework 4.8 (Windows)
  • Mono Runtime (Linux / macOS)
  • 64-bit OS (x64 architecture)
  • OpenGL 3.0+ GPU
