About this documentation

These pages describe the Dust765 Ultima Online client — a fork of ClassicUO developed in the open-source repo dust765/ClassicUO. They mirror the GitHub wiki so you can read features, settings, and behaviour alongside the source.

When you work locally, keep this site next to your checkout of that repository (for example the ClassicUO tree under your workspace) so documentation and code stay easy to cross-reference.

🎮 How to Use

Feature activation

  1. Access Options: Open the Options gump (game menu or hotkey).
  2. Navigate categories: Every Options sidebar entry has its own accordion below (ClassicUO + Dust765). Labels match OptionsGump.cs. Each control row includes an image or video placeholder for you to fill in.
  3. Order: General → Sounds → Video → Macros → Tooltips → Fonts → Speech → Combat → Counters → InfoBar → Action Bar → Containers → Experimental → Ignore list button → Dust → 765 → Mods → Nameplate Options → Cooldowns → Grid Container → Profiles.
  4. Configure settings as needed.
  5. Save: Settings are saved automatically.

Broken features

  • WireFrame View: currently non-functional.
  • Black Outline Statics: currently broken.

Requirements

  • Some features require a client restart.
  • Certain options depend on other settings being active.
  • Check compatibility with your server version.

Performance

  • Visual features may impact FPS.
  • Auto loot may cause lag in areas with many items.
  • Transparency and invisibility may affect rendering.
